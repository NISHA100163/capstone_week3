PROJECT DESCRIPTION

A modern frontend for secure online shopping

Secure Retail Store was developed as a multi-page website using HTML and CSS. The project allows users to browse products, access account pages, view their shopping cart and contact the support team.

The website was created from the project wireframes, MVP features and user stories developed during the earlier sprint. The frontend focuses on clear navigation, consistent styling and responsive design.

HTML Semantic webpage structure
CSS Styling and responsive layouts
GitHub Team collaboration and version control
PROBLEM STATEMENT

Why was Secure Retail Store created?

Many online retail websites can be confusing, inconsistent or difficult to use, particularly for customers who need a simple and trustworthy shopping process.

01

Complex navigation

Customers may struggle to locate products, account pages, carts or support information when navigation is unclear.

02

Inconsistent design

Different page layouts, colours and typography can make an online store feel unreliable and difficult to understand.

03

Limited mobile usability

Websites that are not responsive can be difficult to use on mobile phones and tablets.

04

Customer security concerns

Customers need clear reminders and trustworthy page designs when entering personal or account information.

OUR SOLUTION

Designed around trust, usability and accessibility

The Secure Retail Store interface provides a clear page structure and consistent visual design across the website.

✓

Simple multi-page navigation

Users can move easily between the homepage, login, admin, cart, About and Contact pages.

✓

Consistent visual design

Shared colours, typography, buttons and layouts create a professional appearance.

✓

Responsive user experience

CSS media queries allow pages to adapt to desktop, tablet and mobile screen sizes.
