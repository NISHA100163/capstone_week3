PROJECT OVERVIEW

A simple and trustworthy retail experience

Secure Retail Store is a multi-page frontend website created using HTML and CSS. It demonstrates how users can explore products, access account pages, manage their shopping cart and communicate with the store.

The website was developed from wireframes, user stories and MVP requirements created during the previous sprint.
